# Contact Form Email Setup Guide

This guide will help you set up the contact form to receive emails when users submit inquiries.

## 📋 What You Have Now

1. **contact-handler.php** - Server-side script that processes form submissions
2. **contact-form.js** - JavaScript that handles form submission with AJAX
3. **Updated HTML form** - Form with proper attributes and validation
4. **Email functionality** - Automatic email sending to your inbox

## 🚀 Quick Setup (5 Minutes)

### Step 1: Update Your Email Address

Open the file `contact-handler.php` and change this line:

```php
// Line 13 - Change this to your actual email
$your_email = "your-email@example.com";
```

**Replace with your actual email:**
```php
$your_email = "sabir@blinkingstars.com";  // Use your real email
```

### Step 2: Upload Files to Your Web Server

Upload these files to your web hosting server:
- `index.html`
- `contact-handler.php`
- `contact-form.js`
- All your other website files

### Step 3: Test the Form

1. Visit your website
2. Fill out the contact form
3. Click "Send Message"
4. Check your email inbox (and spam folder)

## 📧 Email Configuration Options

### Option A: Basic PHP Mail (Simplest)

**Pros:** Works on most shared hosting
**Cons:** Emails might go to spam

The current setup uses PHP's built-in `mail()` function. No additional configuration needed.

### Option B: SMTP Configuration (Recommended)

For better email delivery, update the PHP file to use SMTP:

```php
// Add this at the top of contact-handler.php after the opening <?php tag
require_once 'PHPMailer/PHPMailer.php';
require_once 'PHPMailer/SMTP.php';
require_once 'PHPMailer/Exception.php';

use PHPMailer\PHPMailer\PHPMailer;
use PHPMailer\PHPMailer\SMTP;

// Replace the mail() function with PHPMailer setup
$mail = new PHPMailer(true);
$mail->isSMTP();
$mail->Host = 'smtp.gmail.com';  // Your SMTP server
$mail->SMTPAuth = true;
$mail->Username = 'your-email@gmail.com';
$mail->Password = 'your-app-password';
$mail->SMTPSecure = PHPMailer::ENCRYPTION_STARTTLS;
$mail->Port = 587;
```

## 🔍 Troubleshooting

### Problem: "Method not allowed" error
**Solution:** Make sure you're accessing the form through a web server, not opening the HTML file directly in browser.

### Problem: Emails not arriving
**Solutions:**
1. Check spam/junk folder
2. Verify email address in PHP file
3. Contact hosting provider about mail function
4. Use SMTP instead of basic mail function

### Problem: Form not submitting
**Solutions:**
1. Check browser console for JavaScript errors
2. Ensure contact-form.js is loaded
3. Verify form ID matches JavaScript

### Problem: "Network error"
**Solutions:**
1. Check if contact-handler.php exists on server
2. Verify PHP file permissions
3. Check server error logs
